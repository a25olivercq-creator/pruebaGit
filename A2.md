## 1. Instalación del Servidor y Cliente SSH

### 1.1 Instalar OpenSSH en el Servidor

*Ejecuta en el equipo remoto al que te vas a conectar*

#### En Debian / Ubunto Linux Mint:

    Bash

    sudo apt update
    sudo apt install openssh-server -y
    
#### En RHEL / CentOS / AlmaLinux / Fedora:

    Bash

    sudo dnf install openssh-server -y

### 1.2 Iniciar y Habilitar el Servicio

*Garantiza que el servicio se inicie automáticamente al arrancar el sistema*

    Bash

    sudo systemctl enable --now ssh  # En Debian/Ubuntu
    # O en RHEL/CentOS:
    sudo systemctl enable --now sshd

### 1.3 Configurar el Firewall

*Permite el tráfico entrante en el puerto SSH (por defecto 22)*

#### En UFW (Ubuntu/Debian):

    Bash

    sudo firewall-cmd --permanent --add-service=ssh
    sudo firewall-cmd --reload

## 2. Autenticación Mediante Claves SSH

Es la forma más segura de conectarse. Evita el uso de contraseñas mediante un par de claves (pública y privada).

**En la máquina cliente (tu ordenador local):**

1. **Generar el par de claves (RSA 4096 o ED25519 - recomendada):**

    ``` Bash
    ssh-keygen -t ed25519 -C "tu_email@ejemplo.com"
    ```

    >(Presiona Enter para guardar en la ruta por defecto /home/usuario/.ssh/id_ed25519).

2. **Copiar la clave pública al servidor remoto:**

        Bash

        ssh-copy-id usuario@ip_del_servidor

3. **Probar la conexión:**

        Bash

        ssh usuario@ip_del_servidor

    >(Ahora debería entrar sin pedirte la contraseña de usuario).
